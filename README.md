# Exam AI 1.2

الواجهة الآن تحتوي بشكل واضح على:
- رفع الكتاب PDF.
- اختيار **الوحدة** بشكل مستقل.
- اختيار **الدرس** داخل الوحدة بشكل مستقل.
- خيار سريع: الكتاب كاملًا / الوحدة / الدرس.
- مستوى سهل / متوسط / صعب.
- عدد الأسئلة.
- نوع السؤال: MCQ / صح وخطأ / مختلط.
- تصحيح النتيجة وشرح الإجابات.

بعد رفع الكتاب، الموقع يستخدم الذكاء الاصطناعي لاستخراج الوحدات والدروس، ثم يرسل نطاق الاختيار المحدد فقط إلى مولّد الامتحان.
